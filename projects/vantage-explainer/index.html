    Production notes

    An explainer for an operations dashboard has to show a system, not a screen. The first half is illustrated in flat isometric: four tools on a factory floor, then lines that pull them into one board. The second half cuts into the product itself, with the dashboard assembling card by card and an incident flowing from alert to resolution.

    The caption track is a separate layer timed to the same clock as the animation, so it can be toggled, restyled or swapped for another language without touching the picture. Every diagram is drawn from data, which makes revisions to numbers or labels a one-line change rather than a re-render.
