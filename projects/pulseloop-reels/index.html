Production notes

Three vertical reels built for sound-off feeds: every number, chart and badge is animated so the message lands without a voice. Cuts land every three to four seconds with a two-frame white flash, and each reel closes on the same logo and call to action so the set reads as one campaign.

The counters, heart-rate trace, calendar grid and breathing circle are all driven from the same clock, so a scrub to any frame gives the exact state a viewer would see at that moment. The top 180 px and bottom 300 px are kept clear of key content to sit under platform overlays.
