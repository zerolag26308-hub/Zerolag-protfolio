Add one snippet this afternoon. See data before you leave.

Install the SDK for JavaScript, Python, Go, Swift or Kotlin, and send your first event in a few lines. The event inspector checks each one against your tracking plan as it arrives, so a broken property gets caught on the day it ships.

// send an event from your app
import { northlane } from
  "@northlane/browser";

northlane.init("nl_demo_7f3a");
northlane.track("doc_shared", {
  plan: "team",
  recipients: 3,
});
